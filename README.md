# تطبيق biaza للدردشة

هذا المشروع يحتوي على كل ما تحتاجه لتشغيل التطبيق محلياً.

## التشغيل محلياً

**المتطلبات المسبقة:**  Node.js


1. تثبيت التبعيات:
   `npm install`
2. قم بتعيين مفتاح API في ملف [.env.local](.env.local)
3. تشغيل التطبيق:
   `npm run dev`
